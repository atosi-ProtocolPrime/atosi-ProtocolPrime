## 🛠️ Featured R&D Prototypes & Architecture

| Project | Stack & Architecture | Core Engineering & Program Value |
| :--- | :--- | :--- |
| **PrimeCapture**<br>*(Local Execution Engine)* | `Python` `FastAPI` `React` `ADB` `Selenium` `OpenCV` `Gemini Vision API` | **Polyglot Visual QA & L10n Auditing Suite:** Orchestrates parallel UI capture across Android (`ADB`/`UIAutomator`) and Web (`Selenium`) environments directly from local developer machines. Uses an autonomous "Discovery Pass" to cache structural blueprints on `en-US` and replay them deterministically across localized builds (`es-ES`, `fr-FR`, `de-DE`, `ja-JP`), paired with multimodal Gemini Vision APIs and automated HTML audit reports to flag UI text clipping and translation regressions. Built with a **Split-Sync Zero-Liability Telemetry** architecture so sensitive screenshots remain 100% air-gapped locally. |
| **PrimeTrack**<br>*(Internal Telemetry)* | `React` `Tailwind CSS` `Firebase` `Firestore` `RBAC` | **Enterprise Program Telemetry & Capacity Engine:** A real-time operational platform built to replace static spreadsheets in high-volume testing cycles. Features an interactive Kanban task engine, Localization Coverage Matrix, Role-Based Access Control (RBAC), and release radar telemetry to model resource allocation and surface critical-path bottlenecks early. |
| **PrimeConnect**<br>*(In Development)* | `React` `WebSockets` `Firebase` `Gemini API` | **Cross-Lingual Sync & HITL Evaluation Engine:** A real-time, privacy-first web application utilizing WebSockets for two-device QR handshakes and dynamic, culturally aware prompt generation. Incorporates a **Human-in-the-Loop (HITL) QA Mode** and **Wilson Score Interval** ranking so native linguistic testers can flag culturally awkward AI outputs and trigger targeted LLM rewrites in real time. |
